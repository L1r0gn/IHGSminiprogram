# 智能作业批改系统
一个基于微信小程序的智能作业批改系统，连接教师与学生，提供便捷的作业布置、提交、批改及学习统计功能。

## 技术栈
*   **前端框架**: 微信小程序原生框架 (WXML, WXSS, JavaScript)
*   **组件框架**: Glass Easel
*   **数学公式**: KaTeX (@rojer/katex-mini)
*   **后端接口**: RESTful API (Django + Django REST Framework)
*   **认证方式**: JWT Token

## 运行方法

### 1. 安装依赖
```bash
npm install
```

### 2. 构建 npm
在微信开发者工具中：点击菜单栏「工具」→「构建 npm」

### 3. 配置后端接口
修改 `app.js` 中的 `globalUrl` 为实际后端服务地址或本地测试地址(例：globalUrl: 'http://127.0.0.1:8000')

### 4. 开发调试
使用微信开发者工具打开项目目录即可开始开发

### 5. 运行测试
```bash
npm test              # 运行测试
npm run test:coverage # 生成覆盖率报告
```

## 主要功能
*   **用户认证**: 微信授权登录，JWT 会话管理
*   **班级系统**: 教师创建班级，学生通过班级码加入
*   **作业系统**: 作业布置、提交、批改、查看详情
*   **题库管理**: 题目搜索、自主练习
*   **数据统计**: 学习数据可视化、知识点掌握分析
*   **知识追踪**: 基于 BKT 算法的学习能力评估
